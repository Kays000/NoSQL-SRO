## 1. Описание проекта

Проект представляет собой работающий прототип подсистемы хранения данных для платформы онлайн-обучения. В системе реализовано разделение ответственности:
* **MongoDB** выступает в роли основного хранилища (Source of Truth) для профилей, каталога курсов с вложенными модулями и записей студентов.
* **Redis** используется как высокоскоростной кэш для карточек курсов (по схеме **Cache-Aside**) и как хранилище структуры **Sorted Set** для поддержания актуального рейтинга популярности курсов.

### Ключевые особенности реализации:
* **Инвалидирование кэша:** при изменении цены курса соответствующий ключ в Redis принудительно удаляется, что исключает выдачу устаревшей информации.
* **Фиксация цены (Snapshot):** в коллекции записей (`enrollments`) сохраняется стоимость курса на момент покупки. Изменение цены в каталоге не затрагивает историю прошлых записей студентов.
* **Защита от дублирования:** уникальный составной индекс по полям `(user_id, course_id)` на уровне MongoDB предотвращает повторную запись студента на один и тот же курс.

3. Системные требования
Для запуска и тестирования прототипа на компьютере должны быть установлены:

Python версии 3.10 или выше.

MongoDB (по умолчанию запускается на локальном порту 27017).

Redis (по умолчанию запускается на локальном порту 6379).

4. Установка и запуск
Шаг 1. Клонирование или открытие проекта
Перейдите в директорию с проектом в терминале.

Шаг 2. Настройка виртуального окружения и установка зависимостей
Рекомендуется использовать изолированное виртуальное окружение:

Bash
# Создание виртуального окружения
python -m venv .venv

# Активация окружения (для Windows PowerShell)
.venv\Scripts\Activate

# Установка зависимостей из requirements.txt
pip install -r requirements.txt
Шаг 3. Настройка конфигурации (опционально)
Создайте файл .env на основе примера .env.example, если ваши экземпляры MongoDB или Redis работают на удаленных серверах или отличных от стандартных портах. По умолчанию скрипт использует локальные адреса:

MONGO_URI=mongodb://localhost:27017

REDIS_URL=redis://localhost:6379/0

Шаг 4. Запуск скрипта
Убедитесь, что службы MongoDB и Redis запущены в системе, после чего выполните:

Bash
python cache_project.py
При запуске скрипт автоматически:

Подключится к обеим базам данных.

Пересоздаст коллекции и сгенерирует 39 синтетических записей (через функцию seed()).

Продемонстрирует работу Cache-Aside, инвалидирования кэша и блокировки дублей.

Выведет результаты 8 аналитических запросов (Q1–Q8).

Запустит блок автоматических тестов (tests()) с проверками assert.

Выполнит сравнительный замер скорости (1000 чтений через MongoDB напрямую против чтения через Redis).

5. Тестирование и проверка
В коде предусмотрен встроенный комплекс проверок (tests()). Если какое-либо из условий нарушится (например, некорректно отработает кэш или пропустится дубль записи), выполнение скрипта остановится с ошибкой AssertionError. Успешное выполнение завершается выводом всех тестов со статусом OK.
