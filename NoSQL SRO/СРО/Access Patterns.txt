ACCESS PATTERNS (вариант 20: платформа онлайн-обучения, MongoDB + Redis)

ID   Паттерн доступа                           Приоритет  Хранилище / операция                                   Ожидаемый результат
AP1  Карточка курса по id                      Высокий    Redis GET course:{id}; при промахе MongoDB find_one    Документ курса; повторно из кэша
AP2  Курсы категории по цене                   Высокий    MongoDB find + sort (Q1)                               Список курсов по возрастанию цены
AP3  Фильтр курсов по цене и тегам             Средний    MongoDB find: $gte, $lte, $in (Q2)                     Курсы в диапазоне цены с нужными тегами
AP4  Курсы студента с прогрессом               Высокий    MongoDB find по user_id (Q3)                           Записи по убыванию прогресса, со snapshot
AP5  Запись студента на курс                   Высокий    MongoDB insert_one + уникальный индекс; ZINCRBY        Запись со snapshot цены; дубль отклонён
AP6  Изменение цены курса                      Высокий    MongoDB update_one + удаление ключа в Redis            Новая цена видна сразу, кэш не отдаёт старое
AP7  Топ популярных курсов                     Средний    Redis ZREVRANGE popular (Q8)                           N курсов с числом записей без обращения к MongoDB
AP8  Аналитика каталога                        Низкий     MongoDB aggregate (Q4-Q7)                              Средняя цена, топ курсов, завершившие, нагрузка преподавателей

Чтений заметно больше, чем изменений: карточки курсов читаются часто, цена и каталог меняются редко.
